###### **Калькулятор (разработка и тестирование)**



**Описание проекта**



В рамках проекта был разработан калькулятор на Python, а так же проведено его функциональное тестирование.



Приложение поддерживает:

* базовые арифметические операции (сложение, вычитание, умножение, деление)
* дополнительные функции (квадрат числа, квадратный корень, обратное значение, вычисление процента, смена знака)
* работу с дробными числами
* системные операции (C, CE, удаление символа)



**Цель проекта**



* Разработать калькулятор
* Провести функциональное тестирование
* Продемонстрировать навыки QA (тест-дизайн, составление тест-кейсов, оформление баг-репортов)



**Объект тестирования**



* Арифметические операции
* Работа с процентами
* Обработка пользовательского ввода
* Поведение при ошибках
* Граничные значения
* Системные функции калькулятора



**Тестирование**



В рамках тестирования:



* составлены тест-кейсы
* покрыты позитивные сценарии
* реализованы негативные сценарии
* протестированы граничные значения
* проверена логика вычислений (включая проценты и приоритет операций)



**Найденные дефекты**



В ходе тестирования были выявлены дефекты, включая:



* некорректное вычисление процентов
* ошибки при делении на ноль
* ошибки при извлечении корня из отрицательного числа
* ошибки при обработке некорректного ввода
* отсутствие ограничений на ввод данных
